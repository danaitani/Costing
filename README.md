# Whole Genome Sequencing Cost-Effectiveness Analysis (Klebsiella pneumoniae, Tunisia)

## Overview
This repository contains the R code used to evaluate the **cost-effectiveness and budget impact of implementing whole genome sequencing (WGS)** for surveillance and infection prevention and control (IPC) of third-generation cephalosporin-resistant *Klebsiella pneumoniae* (3GCR-Kp) in Tunisia.

The analysis integrates:
- Micro-costing of WGS
- Transmission-informed infection prevention impact
- Deterministic cost-effectiveness modelling
- One-way sensitivity analysis (OWSA)
- Probabilistic sensitivity analysis (PSA)
- Cost-effectiveness acceptability curves (CEAC)
- Budget impact analysis (BIA)

All costs are reported in **2022 USD**.

---

## Objectives
The model estimates:
- Cost per infection averted (CPIA)
- Net programme cost
- Infections and bed-days averted
- Probability of cost-effectiveness
- Budget impact across hospital, national reference laboratory (NRL), and system levels

---

## Data Sources
The analysis uses:
- Routine surveillance data from the **Tunisian AMR Surveillance System (TARSS)**
- Hospital-level antibiotic consumption and infection burden
- Micro-costing inputs for WGS 
- IPC and epidemiological assumptions informed by observed transmission clusters
